# 一般要求

并网逆变器应满足所适用并网电压等级的并网要求，具备可设定的输出有功与无功能力。逆变器铭牌参数应与检测报告一致，并取得相应检验报告后方可并网使用。

# 转换效率与电能质量

逆变器最大转换效率与加权效率应不低于企业标称值与国家标准限定值。逆变器输出电流的谐波含量应满足并网电能质量要求，功率因数在额定输出范围内应达到规定值，具备一定无功调节范围以配合电网电压调节。

# 保护功能

逆变器应具备并网侧过欠压保护、过欠频保护、短路保护与直流侧极性反接保护。当电网电压或频率越限时应按规定时限自动停机并告警，电网恢复后再并网应满足再并网延时要求。

# 防孤岛保护

逆变器应具备有效的防孤岛保护功能，采用主动与被动检测相结合的方式，在电网失电后规定时间内检测到孤岛并停止向电网送电，防止非计划孤岛运行危及检修人员安全与设备安全。

# 可靠性与环境适应性

逆变器外壳防护等级与温升应满足户外或户内使用环境要求，应具备完善的风冷或散热设计。关键元器件应符合耐久性要求，产品应提供明确的质保与售后服务条款。
