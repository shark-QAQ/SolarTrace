# 站址与总平面

光伏发电站站址选择应避开地质灾害易发区、行洪区与自然保护区核心区，并统筹考虑日照资源、地形坡度与输电线路接入条件。组件阵列布置应根据纬度确定倾角，兼顾前后排间距以避免阴影遮挡损失。

# 组件与支架布置

组件阵列的排布方向、倾角与间距应结合当地气象条件确定，寒冷地区应核算风、雪荷载对支架与基础的影响。支架基础应满足承载力与抗拔要求，桩基或条形基础施工应符合设计要求。

# 电气系统设计

光伏方阵经汇流后接入逆变器，逆变器输出经升压变压器接入电网。直流侧应配置汇流箱与直流开关，具备防反接与过流保护；交流侧应配置并网开关、计量装置与继电保护。电缆选型与敷设应满足载流量、耐候性与防火要求。

# 接地与防雷

光伏发电站应设置完善的接地系统，组件金属边框、支架、逆变器外壳等应可靠接地。光伏系统宜按建筑物防雷类别配置接闪装置或采取等电位连接措施，接地电阻应满足规范要求。

# 消防与安全

站区应合理布置检修通道与消防通道，电气设备用房应满足防火分隔要求，配置适用的消防器材与应急照明。运维人员安全防护用品与安全标识应齐全。
