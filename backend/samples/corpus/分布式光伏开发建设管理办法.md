# 适用范围与分类

本办法适用于分布式光伏发电项目的开发建设与运行管理。分布式光伏发电是指在用户所在场地或附近建设运行、以用户侧自发自用为主、多余电量上网且在配电网系统平衡调节为特征的光伏发电设施。

按照投资主体与并网容量，分布式光伏可分为自然人户用分布式光伏、非自然人户用分布式光伏、一般工商业分布式光伏和大型工商业分布式光伏等类别。

# 项目备案

分布式光伏发电项目实行备案管理。户用分布式光伏项目可简化备案流程，由电网企业代为办理或由项目业主按规定向所在地能源主管部门备案。工商业分布式光伏项目应由投资主体依法办理备案手续，取得备案文件后方可开工建设。

备案文件应与项目建设规模、建设地点保持一致。任何单位不得以任何名义要求分布式光伏项目捆绑配置储能、购买本地光伏产品作为核准或并网前置条件。

# 并网与电网服务

电网企业应简化分布式光伏并网流程，公开并网受理条件与办理时限。项目并网前应完成接入系统方案的确认，并网验收合格后方可并网运行。分布式光伏项目上网电量按结算周期计量，电网企业应按规定及时足额结算电费。

对自然人户用分布式光伏项目，电网企业应保障便捷接入，不得无正当理由拒绝或拖延并网。对超出本地消纳能力的区域，电网企业应及时公布可开放容量并合理安排开发时序。

# 建设与安全红线

分布式光伏项目应符合电力安全相关标准，不得降低安全防护要求。不得在已并网项目中擅自增加容量或改变安装位置规避备案监管，不得将备案项目拆分为多个小容量项目以规避备案管理要求。未经许可，不得擅自将分布式项目转为集中式或以其他方式规避管理。

# 运行维护要求

项目业主与运维单位应加强设备巡检，确保组件、逆变器及防雷接地设施状态良好。发生重大设备故障或安全事件时，应按要求向当地能源主管部门与电网企业报告，并及时整改。
