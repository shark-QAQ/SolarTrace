# 并网点与电气要求

光伏发电站应在并网点处与电网保持电压、频率和相位一致。并网逆变器与变压器的容量、电压等级配置应满足并网接入方案要求，并网点应具备可操作、可断开的并网开关。

# 电能质量要求

光伏发电站接入电网后，注入电网的谐波、电压波动与闪变应满足电能质量相关国家标准要求。大功率设备启停、辐照变化引起的有功出力波动，应通过逆变器功率控制与储能或无功调节手段加以平抑。

# 保护与安全

光伏发电站应配置防孤岛保护、过欠压保护与频率保护，当电网失压或检测到孤岛运行时应快速断开与电网的连接。逆变器应具备主动与被动结合的防孤岛检测能力，并网开关应具备就地与远方操作功能。

# 低电压穿越与无功能力

并网光伏电站应具备规定的低电压穿越能力：在电网发生一定深度与持续时间内的电压跌落时，电站不得脱网，并应按要求向电网提供无功支撑。电站的动态无功响应与功率因数调节范围应满足电网调度要求。

# 调度与信息交互

纳入调度管理的光伏电站应按要求配置测控与通信装置，向调度机构上传有功、无功、电压、开关状态等运行信息，并服从调度指令。
