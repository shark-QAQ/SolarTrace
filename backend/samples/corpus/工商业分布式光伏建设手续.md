# 立项与消纳形式确定

工商业分布式光伏项目业主应根据企业用电负荷与屋顶面积，确定自发自用、余电上网或全额上网等消纳形式，并结合变压器容量测算可接入容量。

一般工商业分布式光伏装机不宜超过其所在配电变压器容量与用电负荷承载能力，具体接入规模以电网企业接入系统方案批复为准。

# 备案与主体要求

项目建设单位应为依法设立、具备相应资质与良好信用的企业法人，并按规定在项目所在地办理企业投资项目备案，取得备案证明。备案内容包括项目名称、建设地点、装机容量、消纳方式与计划开工时间。

# 前期手续清单

业主通常需完成以下手续：屋顶产权或租赁权属证明、企业营业执照、项目备案、电网接入系统方案申请与批复、设计单位出具的施工图、以及涉及消防、结构安全评估所需的资料。若厂房为租赁，应取得产权人同意并约定责任。

# 开工与验收衔接

取得备案与接入批复后方可组织施工。项目建成后由电网企业与业主按并网验收标准组织验收，验收合格并签订购售电合同或市场化交易协议后并网运行。全流程文件应归档保存以备主管部门抽查。
