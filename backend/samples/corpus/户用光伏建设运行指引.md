# 户用光伏是什么

户用光伏是指在居民自有住宅或合法产权建筑物屋顶建设的分布式光伏发电设施，所发电量可优先满足家庭自用，余电上网销售。其安装容量通常较小，一般由自然人业主投资建设。

# 备案与手续

户用光伏项目建设前应确认房屋产权清晰、屋顶承载满足要求。备案由项目业主或委托电网企业代为办理，需提供身份证明、房屋产权证明及拟建方案。完成备案后由电网企业出具接入意见。

安装光伏不得占用公共区域或影响邻里采光、通风及消防通道。涉及公共区域或第三方共有部分屋顶的，应取得相关权利人同意。

# 并网验收与安装

户用光伏并网前由电网企业开展并网验收，重点检查逆变器是否具备防孤岛保护、计量表计是否规范安装、接入方式是否符合低压并网要求。验收不合格的需整改后重新验收。

组件安装宜朝南布置并保证通风散热，屋面防水层不得破坏。电气接线应由持证电工实施，加装隔离开关与防雷保护装置。

# 电费结算

户用光伏上网电量由电网企业按结算周期抄表计量，并按当地燃煤基准价与相关政策形成的上网电价结算。自发自用部分按目录电价或市场化电价与用电户结算，具体以合同约定为准。

# 常见问题提示

若屋顶产权存在争议或房屋列入征迁范围，建议暂缓建设。户用光伏保险可由业主自愿购买，用于覆盖设备与第三者责任风险。
