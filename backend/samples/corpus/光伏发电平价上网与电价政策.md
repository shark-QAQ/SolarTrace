# 平价上网政策背景

自国家将光伏发电由补贴推动转向市场驱动以来，新备案的集中式光伏电站与工商业分布式光伏项目原则上实行平价上网，不再执行固定标杆补贴电价，由项目通过市场化方式获得收益。

# 户用与分布式电价结算

对户用分布式光伏，其上网电量电价按国家明确的政策机制形成并逐年向市场化过渡。自发自用、余电上网项目的自用电量按户主与电网约定的用电价格结算，上网电量按上网电价单独计量结算。

# 市场化交易与绿证

具备条件的发电项目可参与电力市场化交易，通过中长期合同、现货市场等方式形成成交电价。光伏发电项目产生的绿色电力可申请绿证，参与绿色电力交易获得环境权益收益。

# 地方支持政策

各地可结合本地实际出台分布式光伏建设支持政策，包括容量开放、金融支持与开发园区集中连片开发等安排。具体执行口径以项目所在地主管部门发布的最新文件为准。
