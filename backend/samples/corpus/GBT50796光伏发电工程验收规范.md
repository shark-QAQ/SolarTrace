# 验收依据与程序

光伏发电工程验收应依据经批准的施工图设计文件、合同文件及相关国家标准进行。工程完成后应依次完成分项工程验收、分部工程验收、单位工程验收与竣工验收，并形成完整验收记录。

# 支架与土建验收

支架基础与结构的施工质量应符合设计要求，重点检查桩基垂直度、预埋件位置、防腐处理与紧固件力矩。组件安装面平整、无划伤隐裂，固定连接可靠，接线盒密封良好。

# 电气与并网设备验收

光伏组件、汇流箱、逆变器、箱变等设备应有合格证明与试验报告。逆变器并网功能、防孤岛保护、通信与计量装置应现场试验合格。直流与交流侧绝缘、接地电阻测试结果应满足规范允许值。

# 调试与试运行

工程投运前应完成整套启动调试与并网试运行，核对保护定值、监控画面与远动信息。试运行期间暴露的问题应整改闭环，形成调试报告与遗留问题清单。

# 竣工验收资料

竣工验收应提交设计文件、竣工图、设备资料、试验调试记录、隐蔽工程验收记录等档案资料。验收合格后由建设、监理、施工单位签署竣工验收意见。
