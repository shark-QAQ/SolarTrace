# 接口设计 · SolarTrace

统一前缀 `/api/v1`；鉴权 `Authorization: Bearer <token>`。错误统一结构：

```json
{ "error": { "code": "RESOURCE_NOT_FOUND", "message": "…", "detail": null } }
```

## 1. 认证与用户

| 方法 | 路径 | 角色 | 说明 |
| --- | --- | --- | --- |
| POST | `/auth/login` | 公开 | body `{username,password}` → `{access_token,user}` |
| GET | `/auth/me` | 登录 | 当前用户 |
| POST | `/auth/password` | 登录 | 改密 `{old_password,new_password}` |
| GET | `/users` | admin | 分页用户 |
| POST | `/users` | admin | 创建 `{username,password,display_name,role}` |
| PATCH | `/users/{id}` | admin | 更新角色/状态/密码 |

## 2. 文档库与索引

| 方法 | 路径 | 角色 | 说明 |
| --- | --- | --- | --- |
| GET | `/documents` | 登录 | 列表：`status/doc_type/keyword/page/page_size` |
| GET | `/documents/{id}` | 登录 | 详情（含元数据） |
| GET | `/documents/{id}/versions` | 登录 | 版本列表 |
| GET | `/documents/{id}/preview` | 登录 | 解析预览（纯文本） |
| POST | `/documents/upload` | editor+ | multipart：`file` + 元数据表单；`publish` 控制是否立即建索引；`document_id` 可选追加版本 |
| POST | `/documents/{id}/publish` | editor+ | body `{version_id?}` 发布建索引（缺省用最新非归档版本） |
| POST | `/documents/{id}/archive` | editor+ | body `{version_id?}` 归档并清理索引 |
| POST | `/system/reconcile` | editor+ | 索引/文档一致性对账 |
| GET | `/system/index-ops` | 登录 | 索引操作流水 |

上传响应：
```json
{ "document": {...}, "version": {...}, "indexed": true }
```
发布响应：在文档/版本上附加 `chunk_count`（片段数）与 `parent_count`（父块数）。

## 3. 检索

| 方法 | 路径 | 角色 | 说明 |
| --- | --- | --- | --- |
| GET | `/search` | 登录 | `q`（必填）、`top_k`；返回改写摘要 + Top-K 命中 |

响应节选：
```json
{
  "question": "...",
  "rewritten": { "original":"…", "expanded":"…", "appended_terms":[…], "doc_type_hint":"…", "year_hint":null },
  "hits": [ { "chunk_id":"…", "rank":1, "score":0.81, "doc_code":"…", "title":"…",
              "section_path":"…", "snippet":"…", "document_id":1, "version_id":6 } ],
  "latency_ms": 120, "store_count": 38
}
```

## 4. 问答（SSE 流式）

`POST /chat/stream`，body `{"question":"…"}`。响应 `text/event-stream`，帧：

```
event: meta
data: {"rewritten":{…},"citations":[{index,doc_code,title,section_path,text,score},…],"count":5}

event: delta
data: {"text":"依据……"}

event: done
data: {"text":"…","grounded":true,"qa_log_id":12,"latency_ms":800}
```

异常帧：`event: error data: {"message":"…"}`。空依据：`done` 帧 `{"empty":true}`。

| 方法 | 路径 | 角色 | 说明 |
| --- | --- | --- | --- |
| GET | `/chat/history` | 登录 | 当前用户问答日志分页 |
| POST | `/chat/{log_id}/feedback` | 登录 | body `{feedback:1|-1}` 记录人工反馈（样本回填） |

## 5. 评测

| 方法 | 路径 | 角色 | 说明 |
| --- | --- | --- | --- |
| GET | `/eval/sets` | 登录 | 评测集列表（含题数） |
| POST | `/eval/sets` | editor+ | 建集：`{name,description,cases:[…]}` |
| GET | `/eval/sets/{id}/cases` | 登录 | 题列表 |
| POST | `/eval/runs` | editor+ | `{eval_set_id, top_k, generate}` 执行评测 |
| GET | `/eval/runs` / `/eval/runs/{id}` | 登录 | 运行列表 / 明细（含逐条 `details`） |

运行响应：`{hit_rate, hit_rate_top1, context_recall, faithfulness(null 表示未生成), case_count, params, details}`。

## 6. 系统

| 方法 | 路径 | 角色 | 说明 |
| --- | --- | --- | --- |
| GET | `/system/health` | 公开 | 存活（应用名/版本/环境） |
| GET | `/system/ready` | 登录 | DB/向量/BM25/嵌入/生成 探活 |
| GET | `/system/stats` | 登录 | 各域计数 + 最近文档 |
| GET | `/system/runtime` | 登录 | 运行时配置与组件健康 |
| GET | `/system/audit` | admin | 审计日志 |
